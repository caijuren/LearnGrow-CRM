## 四、问题与解决

### 4.1 TypeScript编译错误

**问题:** Fastify schema不支持tags、summary、description属性

**错误信息:**
```
api/routes/user-delete.routes.ts(23,7): error TS2353: Object literal may only specify known properties, and 'tags' does not exist in type 'FastifySchema'.
```

**解决方案:** 从schema中移除所有非JSON Schema标准属性（tags、summary、description），仅保留params、body、querystring、response等标准字段。

### 4.2 环境变量未加载

**问题:** BACKUP_ENCRYPTION_KEY添加到.env.production后，PM2进程未识别

**原因:** `pm2 reload`不会重新读取ecosystem.config.cjs文件

**解决方案:** 
1. 在ecosystem.config.cjs的env配置中显式添加BACKUP_ENCRYPTION_KEY
2. 使用`pm2 stop` + `pm2 start --update-env`完全重启进程

### 4.3 测试脚本环境问题

**问题:** 直接运行`npx tsx scripts/test-encryption.ts`报错BACKUP_ENCRYPTION_KEY未设置

**原因:** 测试脚本在独立shell进程中运行，不继承PM2的环境变量

**解决方案:** 通过`pm2 env 19`提取环境变量并传递给测试脚本
